Ans 3. Difference between Internal and External commands in Linux:

1. Internal Commands: These are built directly into the Linux Shell (Bash). Loaded into RAM memory with shell itself. Examples: cd, pwd, echo, exit.

2. External Commands: Executables stored in disk directories such as /bin, /usr/bin. Executed via child process via fork/exec system calls. Examples: cat, grep, ls.

3. Speed: Internal runs faster (no disk I/O). Everyday analogy: internal commands are like our natural breath inside body, external is drinking water from outside bottle.
